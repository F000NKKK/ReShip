# Support

ReShip is currently a pre-1.0 bootstrap project. No production compatibility or migration guarantee is declared yet beyond the architecture and explicit RSP versioning rules in this repository.

Use GitHub issues for reproducible defects and public feature discussions. Maintainer roadmap work is tracked in YouTrack project ReShip (`RS-*`). Security-sensitive reports must follow `SECURITY.md` instead of public issues.

When reporting a defect, include ReShip/RSP version or commit, OS/runtime, deployment topology (origin/CDN/region where relevant), expected/actual behavior, logs, and whether the failure occurred during discovery, download, verification, staging, activation, rollback, or restart.
