# Research rules

- Start from repository evidence and the active `RS-*` scope.
- For external protocol/CDN/object-storage/OS behavior, prefer primary specifications/vendor documentation and record links/evidence in the YouTrack comment.
- Distinguish confirmed behavior, inference, proposed design and future work.
- Do not infer support from dependency names or test names alone.
- For security/integrity/update activation claims, verify the actual trust boundary and failure mode.
- Keep research read-only unless explicitly assigned an implementation slice.
- Recommend the smallest next bounded task rather than silently implementing adjacent roadmap work.
